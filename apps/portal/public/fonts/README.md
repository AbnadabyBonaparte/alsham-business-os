# Fontes auto-hospedadas

As três famílias da IDENTIDADE-VISUAL §4, em arquivos variáveis (subset latin),
servidas por nós — **sem dependência de rede no build nem em runtime externo**:

| Arquivo | Família | Eixos | Licença |
|---|---|---|---|
| `fraunces-var.woff2` | Fraunces (display) | opsz 9–144 · wght 300–700 | OFL 1.1 |
| `fraunces-var-italic.woff2` | Fraunces Italic | opsz 9–144 · wght 300–700 | OFL 1.1 |
| `inter-var.woff2` | Inter (UI) | wght 100–900 | OFL 1.1 |
| `jetbrains-mono-var.woff2` | JetBrains Mono (código) | wght 100–800 | OFL 1.1 |

Todas sob a [SIL Open Font License 1.1](https://openfontlicense.org/) —
uso, redistribuição e auto-hospedagem permitidos. Os `@font-face` vivem em
`src/app/globals.css`. Peso total: ~237 KB, cacheável, `font-display: swap`.
